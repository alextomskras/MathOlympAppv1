# Jetpack Compose Expert

## Основные принципы:

- Stateless composables (поднимай состояние вверх)
- Unidirectional data flow
- Composition over inheritance
- Reusable и тестируемые компоненты

## Performance:

- Используй remember для вычислений
- Применяй derivedStateOf для производных состояний
- Избегай recomposition storms
- Используй LaunchedEffect для side effects

## UI Patterns:

- Material Design 3 components
- Modifier chain optimization
- LazyColumn/LazyRow для списков
- Navigation Compose с type-safe arguments
