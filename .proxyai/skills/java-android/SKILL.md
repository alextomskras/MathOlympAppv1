# Java Android Development

## Основные принципы:

- Следуй **MVVM** или **MVP** паттернам
- Используй **RxJava** или **LiveData** для реактивности
- Применяй **Dependency Injection** (Dagger/Hilt)
- Соблюдай **SOLID** принципы

## Правила кодирования:

- Используй аннотации @Override, @Nullable, @NonNull
- Применяй try-with-resources для AutoCloseable
- Избегай утечек памяти (Context, View)
- Используй WeakReference для AsyncTask/Handlers

## Android SDK:

- Activity/Fragment lifecycle management
- Intent и Bundle для передачи данных
- RecyclerView с ViewHolder pattern
- AsyncTask/Executors для фоновых операций
