Как плоский список MinIO привязан к разделу и номеру задачи

Идея одна: сквозной номер = сколько задач стоит левее этого раздела + номер задачи внутри раздела. Папок по разделам в MinIO нет — только нумерованные объекты.

1. Firabase RTDB (как сейчас, номера только внутри раздела)

Zadachi/
├── razdel_1/   zadacha_1, zadacha_2, zadacha_3, zadacha_4, zadacha_5   (5 задач)
├── razdel_2/   zadacha_1, zadacha_2, zadacha_3, zadacha_4              (4 задачи)
└── razdel_3/   zadacha_1, zadacha_2, zadacha_3, zadacha_4, zadacha_5, zadacha_6  (6 задач)

2. Считаем смещение разделов (цифра в конце ключа = номер раздела)

РазделЗадачЗадачи левее (смещение offset)Диапазон сквозных номеров
razdel_1501 … 5
razdel_2456 … 9
razdel_365+4=910 … 15

3. Плоский список MinIO — ровно 15 объектов, порядок = сквозной номер

tasks/1/answer.jpg      razdel_1 / zadacha_1
tasks/1/solution.jpg    razdel_1 / zadacha_1
tasks/2/answer.jpg      razdel_1 / zadacha_2
...
tasks/5/solution.jpg    razdel_1 / zadacha_5
tasks/6/answer.jpg      razdel_2 / zadacha_1   (6 = 5 задач r1 + 1)
tasks/7/answer.jpg      razdel_2 / zadacha_2
tasks/8/answer.jpg      razdel_2 / zadacha_3
tasks/9/solution.jpg    razdel_2 / zadacha_4
tasks/10/answer.jpg     razdel_3 / zadacha_1   (10 = 5+4 + 1)
...
tasks/15/solution.jpg   razdel_3 / zadacha_6

4. Как приложение считает для текущей задачи

Открыта razdel_2, zadacha_3:

номер раздела:  razdel_2 -> 2
задачи левее:   раздел 1 = 5  -> offset = 5
сквозной:       offset + номер задачи = 5 + 3 = 8
запрос прокси:  POST {"global": 8, "kind":"answer"}  (подпись X-Auth)
ответ прокси:   {"url": "presigned на tasks/8/answer.jpg"}

В MinIO за это отвечает одна строка маппинга: global = offset(раздел) + номер_задачи. Отдельной таблицы соответствий «раздел -> папки» нет и не нужно.

5. Почему в Firabase это не хранилось

В RTDB нет поля «сквозной номер», нумерация разделов тоже не хранится — она выводится из цифр в ключах (razdel_12 = 12). Поэтому номер считается на телефоне при загрузке картинки; сервер прокси просто принимает global и открывает tasks/<global>/kind.jpg.

6. Старая дорога (Firebase Storage, путь parts[4])

Старый путь картинок разбивается по слешам и берётся 5-я часть — это имя файла, список файлов берётся по позиции задачи в списке раздела. Эта схема остаётся запасной, если прокси выключён: Firebase Storage не ломается, а MinIO включается тумблером в Settings.

7. Загрузчик

proxy/upload_images.py делает ровно тот же пересчёт, что приложение: читает JSON-выгрузку Zadachi, считает offset, кладёт файлы <раздел>/answer_3.jpg -> tasks/8/answer.jpg. Номера в приложении и в MinIO совпадают по построению.
